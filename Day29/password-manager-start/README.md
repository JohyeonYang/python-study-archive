# Day 29 - Password Manager GUI App

## Project Overview

The goal of this project is to build a Password Manager application using Python and Tkinter.

The app allows users to save website login information, including:

- Website name
- Email or username
- Password

It also includes a password generator to help users create strong random passwords.

## What I Learned

Through this project, I practiced:

- Creating a GUI application with Tkinter
- Using labels, buttons, and entry fields
- Working with grid layout
- Creating a password generator
- Copying text to the clipboard
- Saving user input into a text file
- Showing popup messages with `messagebox`
- Checking whether input fields are empty
- Organizing a small Python GUI project

## Features

- User-friendly GUI
- Input field for website name
- Input field for email or username
- Input field for password
- Generate random secure password
- Copy generated password automatically
- Save login information to a text file
- Warning message when fields are empty
- Confirmation popup before saving data
