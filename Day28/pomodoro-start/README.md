Day 28 - Pomodoro Timer GUI App

Project Overview

This project is part of Angela Yu's Python Bootcamp Day 28.

The goal of this project is to build a Pomodoro Timer application using Python and Tkinter.  
The app helps users manage their study or work time by following the Pomodoro technique.

A typical Pomodoro cycle consists of:

- 25 minutes of work
- 5 minutes of short break
- 20 minutes of long break after several work sessions

---

What I Learned

Through this project, I practiced:

- Creating a GUI application with Tkinter
- Using the `Canvas` widget
- Adding images to a Tkinter window
- Using `after()` to create a countdown timer
- Updating labels dynamically
- Working with global variables
- Understanding dynamic typing in Python
- Structuring a small GUI project

---

Technologies Used

- Python
- Tkinter

---

Features

- Start button to begin the timer
- Reset button to stop and reset the timer
- Countdown timer display
- Work session timer
- Short break timer
- Long break timer
- Check marks to show completed work sessions
